# OPG intelligence architecture

The local vision boundary is authoritative. Protected bytes pass through a deterministic quality gate, then independently versioned tooth, restoration, endodontic, pathology, periodontal, and impaction components. A registry enables a component only when its artifact exists, checksum/model manifest is valid, and every training dataset is production-approved. Missing models return `MODEL_REQUIRED`; they never trigger mock findings.

The initial model registry is intentionally empty. Tooth mapping provides only a complete-arch geometry smoke foundation; missing, displaced, impacted, or abnormal dentition requires a trained mapper. Recommended future permissive implementations are torchvision/MONAI Mask R-CNN or U-Net-family models, exported to ONNX after parity tests. Ultralytics is not a production dependency.

Risk is a clinic-approved policy interface. The bundled placeholder contains no active interval. Longitudinal comparison consumes independently inferred structured results and reports new/stable/resolved observations with projection-geometry caveats. Groq receives JSON evidence only and is optional; raw radiographs are never transmitted.
